# BizChat Admin (frontend)

Liquid Glass panel: Vite + React + TypeScript + Tailwind.

```bash
npm install
npm run dev     # http://localhost:5173
npm run build   # production bundle
```

Set `VITE_API_URL` (default `http://localhost:8000`) when API is not on localhost:8000.

Demo: `owner@bizchat.local` / `changeme`
